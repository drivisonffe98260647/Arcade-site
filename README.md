# Arcade UI Demo — Next.js

Interface mobile-first inspirada no layout fornecido: header, banners, categorias,
cards de jogos, drawer lateral e navegação inferior.

## Rodar

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Observação

Este projeto é somente uma interface/demo. Não implementa apostas, carteira de
dinheiro real, depósitos, saques, processamento de pagamentos ou integração com
provedores de jogos. Para um produto real, esses componentes exigem requisitos
legais, regulatórios, de segurança e de conformidade adequados à jurisdição.
